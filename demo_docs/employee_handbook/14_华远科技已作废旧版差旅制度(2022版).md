# 华远科技集团已作废旧版差旅管理制度（2022年暂行版）

> **【状态提示：已废止 / SUPERSEDED】**  
> **文档编号**：HY-FIN-2022-OLD-002  
> **生效时间**：2022年01月01日 至 2023年12月31日  
> **废止通知**：经集团管理层决议，本制度已于 **2023年12月31日24:00 正式废止失效**。自 2024年01月01日起，全集团差旅审批、定额标准及报销清结算一律全面执行最新修订生效的 **HY-FIN-2024-002《华远科技集团差旅与报销管理制度（2024版）》**。本文件仅作为历史档案存档备查，严禁作为当前差旅报销与财务审批之有效依据！

---

## 第一章 历史差旅交通与食宿标准（已失效，勿执行）

### 第一条 2022版出差交通工具审批等级（已作废）
1. **飞机经济舱**：仅限总监级（M4/P8）及以上人员因紧急商务事项报经分管副总裁特批后方可乘坐，其余普通员工一律乘坐普通高铁二等座或硬卧。
2. **私家车公务出行（已作废）**：
   - 经直线部门经理审批同意自驾出差的，过路过桥费凭票实报实销。
   - 燃油及车辆损耗综合补贴基准为人民币 **0.8 元 / 公里**（注意：2024年现行有效标准已提升调整为 1.2 元 / 公里）。
   - 单程自驾补贴里程上限为 300 公里。

### 第二条 2022版差旅住宿城市标准（已作废）
出差人员住宿费实行历史限额标准（含服务费与增值税发票，不得超标）：
- **一类城市（北京、上海、广州、深圳）**：
  - 高管级（M5/P9 及以上）：人民币 700 元 / 间夜；
  - 部门经理/总监（M3 - M4 / P6 - P8）：人民币 **450 元 / 间夜**（注意：2024年现行有效标准中 M3 级别已提升至 600 元 / 间夜）；
  - 普通员工（M1 - M2 / P1 - P5）：人民币 350 元 / 间夜。
- **二类城市（各省会城市及重点计划单列市）**：
  - 部门经理/总监（M3 - M4）：人民币 350 元 / 间夜；
  - 普通员工（M1 - M2）：人民币 260 元 / 间夜。
- **三类城市（其他地级市及县级市）**：
  - 全员统一标准上限为人民币 200 元 / 间夜。

## 第三章 历史差旅伙食与市内交通包干（已失效，勿执行）

### 第三条 2022版出差餐补与市内公杂费（已作废）
1. **伙食补助费**：
   - 按出差自然天数计发，不区分城市类别，历史包干标准为人民币 **80 元 / 人 / 天**（注意：2024年现行有效标准为 100 元 / 人 / 天）。
   - 若出差当日已发生客户商务招待并报销餐费的，当日个人餐补一律不得重复计发。
2. **市内交通包干补贴**：
   - 出差期间市内公共交通历史补贴标准为人民币 **50 元 / 天**（注意：2024年现行有效标准为 80 元 / 天）。
   - 若出差期间租车或有会务专车接送，则不予发放交通补贴。

## 第四章 历史报销时限与纸质单据流转（已失效，勿执行）

### 第四条 历史报销申报周期（已作废）
- 2022年旧版规定员工可在出差行程结束回司后 **60 个自然日内** 提报报销申请（注意：2024年现行有效制度已严禁拖延，明确要求出差结束后 **30 个自然日内** 必须完成系统提交与报销清结，超期系统将强制冻结）。
- 2022年旧版报销需打印纸质贴票凭证，由财务专员手工验真发票并经三道纸质签批。
