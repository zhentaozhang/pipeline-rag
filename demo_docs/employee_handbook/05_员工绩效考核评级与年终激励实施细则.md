# 华远科技集团员工绩效考核评级与年终激励实施细则（2026年版）

**版本**：V2.1  
**生效日期**：2026年1月1日  
**发布机构**：集团人力资源部与薪酬委员会  

---

## 第一章 总则与考核周期

### 第1条 目的与适用范围
1.1 为贯彻“务实高效、结果导向”的核心价值观，建立客观公正的价值评价与分配体系，激发组织与员工活力，特制定本细则。  
1.2 本细则适用于华远科技集团全体正式在册员工（试用期员工入职未满3个月的不参与当年年度评级，仅参与试用期转正考核）。  
1.3 考核周期分为：
- **季度考核（Q1/Q2/Q3/Q4）**：侧重目标关键结果（OKR/KPI）进度跟踪与过程辅导，作为季度奖金发放依据。
- **年度考核**：每年12月启动，次年1月完成，作为年终奖折算、年度调薪及职级晋升的核心依据。

## 第二章 绩效评级与强制分布

### 第2条 绩效等级划分与定义
绩效评价采用六级制评定：
- **S 级（卓越贡献）**：全面超越预期，产生重大业务突破或技术壁垒突破，展现行业顶尖专业水平。
- **A 级（超出预期）**：高质量完成全部目标，在核心指标或关键难点上有突出成果，具备良好协作精神。
- **B+ 级（优秀达成）**：完全达成预定目标，并在部分关键项目中有超出平均水平的交付质量。
- **B 级（符合预期）**：达成既定工作目标，交付质量合格，未发生重大差错或延期。
- **C 级（需要改进）**：部分关键目标未达成，工作产出存在质量缺陷，经辅导后改善不明显。
- **D 级（不符合要求）**：严重未达成工作职责目标，或发生重大业务责任事故，违背公司核心价值观。

### 第3条 部门强制分布比例
为避免平均主义与考核通胀，以一级部门（或事业部）为单位实施严格的钟形强制分布：
| 绩效等级 | 强制分布比例上限 | 说明 |
| :---: | :---: | :--- |
| **S 级** | ≤ 10% | 卓越贡献，须经跨部门评审委员会答辩 |
| **A 级** | ≤ 25% | 超出预期，部门内部平衡控制 |
| **B+ 级** | ≤ 30% | 优秀骨干员工 |
| **B 级** | 30% ~ 40% | 基石员工，部门中坚力量 |
| **C 级** | ≥ 5% | 启动绩效改进计划（PIP），辅导期为30天 |
| **D 级** | 实行淘汰或协商解除 | 连续两次 D 级或单次重大事故直接判定 |

## 第三章 年终奖金折算系数与发放

### 第4条 年终奖计算公式
4.1 员工年度年终奖金计算公式如下：
$$\text{年终奖实发金额} = \text{目标年终奖基数} \times \text{公司年度经营系数} \times \text{部门组织绩效系数} \times \text{个人绩效折算系数}$$

4.2 个人绩效折算系数对照表：
- **S 级**：个人系数为 **2.0**
- **A 级**：个人系数为 **1.5**
- **B+ 级**：个人系数为 **1.2**
- **B 级**：个人系数为 **1.0**
- **C 级**：个人系数为 **0.5**（取消当年晋升资格，暂停年度调薪）
- **D 级**：个人系数为 **0.0**（不发放年终奖，进入淘汰或调岗流程）

4.3 发放时间：年终奖于次年春节前一次性随1月薪资发放。在奖金发放日前已离职或提出书面辞职的员工，不享受当年年终奖金。

## 第四章 股权激励与期权成熟归属机制

### 第5条 期权激励资格与授予
5.1 股权激励面向职级在 **P7 及以上、M3 及以上** 且年度考核为 **A 级及以上** 的核心骨干员工。  
5.2 期权授予采用 **四年成熟期（Vesting Period）** 机制，服务满一年起生效：
- 第 1 年届满：成熟并归属授予总量的 **25%**；
- 第 2 年届满：成熟并归属授予总量的 **25%**；
- 第 3 年届满：成熟并归属授予总量的 **25%**；
- 第 4 年届满：成熟并归属授予总量的 **25%**。

5.3 员工离职处理：
- 正常离职：已成熟归属的期权允许在离职之日起 **90 天内** 行权；未成熟归属的期权自动失效由公司期权池收回。
- 因重大过失（D级或违反安全红线）辞退的员工，未成熟及已成熟但尚未行权的期权全部无偿注销。
